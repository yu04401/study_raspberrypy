ビルドと書き込み:

set(PICO_BOARD pico2_w) を忘れると、RP2040 用にビルドされたり、Wi-Fi/基板上LED 関連のシンボルが見つからなかったりします。設定を変えたら build フォルダを消して cmake し直しましょう。

📍 Pico 2 W ピン配置（よく使う電源ピン）

ADC電源GND

GND は物理ピン 3, 8, 13, 18, 23, 28, 33(AGND), 38 にあります。GP23・24・25・29 は Wi-Fi チップ用で外に出ていません。

⚠ 安全のための約束

  • 配線を変えるときはUSB を抜いてから。
  • 3V3 と GND、VBUS と GND を直接つながない（ショート）。通電前に必ず見直す。
  • GPIO から流す電流は数 mA まで。モータ・ブザーなどはトランジスタやドライバ経由で。
  • 5V の信号を ADC ピン（GP26〜28）に入れない。デジタルピンも分圧かレベル変換を基本にする。
  • IC・電解コンデンサ・LED・ダイオードの向きを確認する。熱い・焦げ臭いと感じたらすぐ USB を抜く。
