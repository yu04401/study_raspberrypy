01外付けLEDを点滅させよう

組み込みの「Hello, world!」。GPIO 出力と、LED を安全に光らせるための抵抗計算を学びます。

  • ⏱ 目安 30分
  • 🔧 回路 + 💻 コード
  • 📚 GPIO出力・電流制限抵抗

🎯 つくるもの

GP15 につないだ赤色LEDと、Pico 2 W の基板上のLEDを 0.5 秒ごとに交互に点滅させます。

🧰 使う部品

  • 赤色LED×1
  • 抵抗 220Ω×1

共通で使うもの: Pico 2 W、ブレッドボード、ジャンパワイヤ、USB ケーブル。

📌 この課題のポイント

  • LED には向き（極性）がある。長い脚 = アノード(+)、短い脚 = カソード(−)。
  • LED は抵抗なしでつなぐと電流が流れすぎて壊れる。オームの法則で抵抗値を決めるのが組み込みの第一歩。
  • Pico 2 W の基板上LEDは GPIO25 ではなく Wi-Fi チップ(CYW43439)の端子につながっている。初代 Pico とはコードが違う。
  • 物理ピン番号（1〜40）と GPIO 番号（GP0〜）は別物。配線ミスの一番の原因なので、常に両方を確認する。

STEP 1回路課題

GP15 から抵抗と LED を通って GND に戻る回路を作ります。次の問いに答えながら配線を考えましょう。

  1. LED の 2 本の脚のうち、長いほうは何極？ GPIO 側（電圧をかける側）につなぐのはどちら？
  2. 赤色LEDの順方向電圧 VF ≒ 2.0V、GPIO の High ≒ 3.3V とします。キットの抵抗（220Ω / 1kΩ / 10kΩ）でそれぞれ何 mA 流れる？ どれを使う？（目安は 5〜10mA）
  3. 抵抗は LED のアノード側とカソード側、どちらに入れるべき？
  4. GP15 は物理ピンの何番？ 近くの GND は何番？
抵抗にかかる電圧は「電源電圧 − LED の VF」。電流は I = (3.3 − 2.0) / R で求まります。
1 本道（直列）の回路では、どこを測っても電流は同じです。
Pico 2 W は USB を上にして左上が物理ピン1（GP0）。左列は上から 1→20、右列は上から 40→21 です。

問いの答えと解説

  1. 長い脚 = アノード(+)。電流はアノード → カソードの向きにしか流れないので、アノードを GPIO 側に、カソードを GND 側につなぎます。
  2. 計算すると次のとおり。220Ω を使います。
    抵抗電流見え方
    220Ω(3.3−2.0)/220 ≒ 5.9mAしっかり光る（採用）
    1kΩ≒ 1.3mA暗いが光る（電池機器ならこれも選択肢）
    10kΩ≒ 0.13mAほぼ見えない
  3. どちらでもOK。直列回路では電流がどこでも同じなので、抵抗の位置で電流は変わりません。
  4. GP15 は物理ピン20（左列のいちばん下）。すぐ上の物理ピン18が GND です。
RP2350 の GPIO の駆動能力は既定で 4mA 設定です（gpio_set_drive_strength() で 2/4/8/12mA に変更可）。 5.9mA 流そうとすると出力電圧がわずかに下がって少し電流が減るだけで、壊れることはありません。

⚠ ハマりどころ

  • ブレッドボード中央の溝をまたがずに LED を差すと、両脚が同じ列でショートして光りません。
  • 長いブレッドボードは電源レール（赤青の線）が中央で途切れているものがあります。
  • 抵抗なしで LED を GPIO に直結しない。LED も GPIO も傷みます。

STEP 2コーディング課題

外付けLEDと基板上LEDを交互に点滅させるプログラムを書きます。

CMakeLists.txt はプロジェクト直下の共通設定（set(PICO_BOARD pico2_w) など）が済んでいる前提です。共通部分は 課題一覧ページ にあります。

要件

  • GP15 を出力に設定する
  • 500ms ごとに外付けLEDの ON/OFF を切り替える
  • 基板上LEDは外付けLEDと逆の状態にする（交互点滅）
  • Wi-Fi チップの初期化に失敗したらメッセージを出して終了する
GPIO の基本は gpio_init(pin) → gpio_set_dir(pin, GPIO_OUT) → gpio_put(pin, 1/0)。待ちは sleep_ms()。
基板上LEDは #include "pico/cyw43_arch.h" して、cyw43_arch_init() の後に cyw43_arch_gpio_put(CYW43_WL_GPIO_LED_PIN, 1)。
リンクするライブラリは pico_stdlib と pico_cyw43_arch_none（Wi-Fi 通信は使わない版）。

解説

  • bool on を反転させて両方の LED に渡すだけで「交互」が作れます。状態を 1 つの変数に持たせると、2 つの LED がずれることがありません。
  • cyw43_arch_init() は Wi-Fi チップのファームウェアを読み込むので、起動に少し時間がかかります。LED のためだけでも必要です。
  • CYW43_WL_GPIO_LED_PIN が未定義エラーになる場合は、CMake で PICO_BOARD が pico2_w になっていません（ビルドフォルダを消して cmake し直す）。

⚠ ハマりどころ

  • 初代 Pico の感覚で gpio_put(25, 1) と書いても Pico 2 W の基板上LEDは光りません。
  • main() から return するとプログラムはそこで止まります。組み込みでは while (true) で回し続けるのが基本です。

✅ 動作確認

🚀 発展課題

  • 点滅パターンを配列（例: {200, 200, 200, 600, ...}）で持たせ、モールス信号の「SOS」を出す。
  • gpio_set_drive_strength() を 2mA と 12mA で切り替えて、明るさが変わるか観察する。
  • LED を 3 個にして、流れるように点灯させる（次の課題 05 の伏線）。
