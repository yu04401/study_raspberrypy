03RGB LEDで虹色グラデーション

PWM で明るさを無段階に変え、3 色を混ぜて好きな色を作ります。

  • ⏱ 目安 60分
  • 🔧 回路 + 💻 コード
  • 📚 PWM・デューティ比・ガンマ補正

🎯 つくるもの

RGB LED の色が10 秒かけて虹色に一周するようにします。人の目に自然に見えるようガンマ補正も入れます。

🧰 使う部品

  • RGB LED×1
  • 抵抗 220Ω×3

共通で使うもの: Pico 2 W、ブレッドボード、ジャンパワイヤ、USB ケーブル。

📌 この課題のポイント

  • PWM = 高速に ON/OFF を繰り返し、ON の割合（デューティ比）で平均の明るさを変える技術。
  • RP2350 の PWM はスライス（12 個）×チャネル A/B。同じスライスの A/B は周波数が共通、デューティは別々。
  • RGB LED には共通アノード型と共通カソード型があり、ON/OFF の論理が逆になる。
  • 人の目は暗い側の変化に敏感。デューティを直線的に変えると明るい側が変化しないように見えるのでガンマ補正する。

STEP 1回路課題

R・G・B の 3 本をそれぞれ抵抗経由で GP13 / GP12 / GP11 につなぎます。まずは手元の RGB LED の型を確かめましょう。

  1. RGB LED の脚は 4 本。いちばん長い脚は何？ 手元の LED が共通アノード型か共通カソード型かを確かめる方法は？
  2. 共通アノード型の場合、長い脚はどこにつなぐ？ 色の脚につながった GPIO を High にすると、その色は点く？ 消える？
  3. GP11 / GP12 / GP13 は、それぞれ PWM の何番スライスのどのチャネル？
  4. 赤（VF≒2.0V）と緑・青（VF≒3.0V）に同じ 220Ω を使うと、何が起きる？
長い脚を 3V3 につなぎ、色の脚を 220Ω 経由で GND に触れて光れば共通アノード型。光らなければ逆に（長い脚を GND、色の脚を 220Ω 経由で 3V3）試します。
スライス番号 = (GPIO 番号 ÷ 2) を 8 で割った余り（RP2350A）、チャネルは GPIO 番号が偶数なら A、奇数なら B。
抵抗にかかる電圧は「3.3V − VF」。青や緑ではこれがかなり小さくなります。

回路図

問いの答えと解説

  1. いちばん長い脚が共通端子です。ヒントの方法で確かめます（このキットの RGB LED は共通アノード型が一般的ですが、必ず実物で確認を）。
  2. 共通アノード型では長い脚を 3V3 へ。電流は 3V3 → LED → GPIO と流れ込むので、GPIO を Low にすると点灯、High で消灯（逆論理）になります。
  3. GPIOスライスチャネル
    GP115B
    GP126A
    GP136B
    G と R は同じスライス 6 なので周波数は共通ですが、デューティは個別に設定できます。
  4. 緑・青は (3.3−3.0)/220 ≒ 1.4mA しか流れず、赤（約 5.9mA）よりかなり暗くなります。白を出そうとすると赤っぽくなるので、赤だけ 1kΩ にするか、ソフトで赤のデューティ上限を下げて色バランスを取ります。

⚠ ハマりどころ

  • 共通アノード型を共通カソード型のつもりで配線すると一切光りません。逆電圧に弱いので長時間は避けましょう。
  • RGB LED の脚は短く密集しているので、ブレッドボードで隣の列に差し間違えやすいです。

STEP 2コーディング課題

3 本の PWM 出力で色相（Hue）を回転させます。

要件

  • GP11〜13 を PWM 出力にし、周波数は 1kHz 以上（ちらつき防止）
  • 明るさは 0〜255 の 256 段階で指定できるようにする
  • ガンマ補正（γ=2.2）をかける
  • 色相 0〜359° を 10 秒で一周させる
  • 共通アノード/カソードの違いはマクロ 1 つで切り替えられるようにする
PWM の設定: gpio_set_function(pin, GPIO_FUNC_PWM) → pwm_gpio_to_slice_num(pin) → pwm_config_set_clkdiv / pwm_config_set_wrap → pwm_init。値は pwm_set_gpio_level(pin, level)。
PWM 周波数 = システムクロック 150MHz ÷ 分周比 ÷ (TOP+1)。TOP=255、分周 64 なら約 9.2kHz。
ガンマ補正は 出力 = 255 × (入力/255)2.2。毎回 powf を計算せず、起動時に 256 要素のテーブルを作っておくと速い。
色相→RGB は 60° ごとの 6 区間に分け、各区間で 1 色だけが増減します（0°赤→60°黄→120°緑→180°シアン→240°青→300°マゼンタ）。

解説

  • ガンマ補正と共通アノードの反転を led_write() の中に閉じ込めたので、呼び出し側は「明るさ 0〜255」だけを考えればよくなっています。ハードウェアの癖を 1 か所に集めるのは組み込みの基本設計です。
  • 反転は pwm_set_output_polarity() でハードウェアに任せる方法もあります。
  • 同じスライスの GP12 と GP13 で pwm_init を 2 回呼んでいますが、設定値が同じなので問題ありません。

⚠ ハマりどころ

  • gpio_init() を呼んだ後に gpio_set_function(..., GPIO_FUNC_PWM) しないと、ピンは普通の GPIO のままで PWM が出ません。
  • 分周比は 1.0〜255.94 の範囲。低い周波数（例: 50Hz）を作るときは TOP を大きくします（課題06）。
